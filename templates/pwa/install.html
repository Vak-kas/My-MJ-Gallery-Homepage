카카오톡·네이버 앱 안에서 열었다면, 오른쪽 위 메뉴의 Safari 로 열기 를 먼저 눌러 주세요. 아이폰 크롬에서도 공유 → 홈 화면에 추가로 돼요.

브라우저 메뉴에서 추가해요

·삼성 인터넷: 아래 메뉴 ≡ → 현재 페이지 추가 → 홈 화면

·크롬 (안드로이드): 오른쪽 위 ⋮ → 앱 설치 또는 홈 화면에 추가

·컴퓨터 크롬·엣지: 주소창 오른쪽의 ⊕ 설치 아이콘

카카오톡 안에서 열었다면 오른쪽 아래 메뉴의 다른 브라우저로 열기 를 먼저 눌러 주세요.
