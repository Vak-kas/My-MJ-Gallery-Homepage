IQ ANALYZER · SDR

IQ 분석기.

GNU Radio 의 File Sink 나 SDR 프로그램으로 저장한 IQ 파일을 열어 시간 파형·스펙트로그램·스펙트럼·성상도를 확대하며 살펴봐요. 파일은 서버로 가지 않고 브라우저 안에서만 읽어요 — 몇 GB 짜리도 필요한 부분만 읽어서 그려요.

📂 IQ 파일을 끌어 놓거나 눌러서 고르기

.cfile · .bin · .dat · .iq (complex float32) · .cs16 · .cs8 · .cu8 · .wav (2채널) · SigMF (.sigmf-meta + .sigmf-data 같이)

GNU Radio 에서 저장하는 법

  • · 흐름도 끝에 File Sink 를 달고 Type 을 complex 로 두면 complex float32 (gr_complex, 샘플당 8바이트) 파일이 돼요. 여기서 기본 형식이 이거예요.
  • · 파일에 샘플레이트가 안 적혀서 직접 넣어야 해요. 파일 이름에 2Msps·fs=2e6·433.92MHz 처럼 적어 두면 알아서 채워요.
  • · SigMF Sink (gr-sigmf) 로 저장하면 샘플레이트·중심 주파수·주석까지 읽어요. 두 파일을 같이 골라 주세요.
  • · 너무 크면 Head 블록으로 샘플 수를 정하거나, 여기서 원하는 구간만 골라 💾 이 구간 저장 으로 잘라 받을 수 있어요.
