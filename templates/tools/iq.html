IQ ANALYZER · SDR

IQ 분석기.

GNU Radio 의 File Sink 나 SDR 프로그램으로 저장한 IQ 파일을 열어 시간 파형·스펙트로그램·스펙트럼·성상도를 확대하며 살펴봐요. 파일은 서버로 가지 않고 브라우저 안에서만 읽어요 — 몇 GB 짜리도 필요한 부분만 읽어서 그려요.

📂 IQ 파일을 끌어 놓거나 눌러서 고르기

.cfile · .bin · .dat · .iq (complex float32) · .cs16 · .cs8 · .cu8 · .wav (2채널) · SigMF (.sigmf-meta + .sigmf-data 같이)

GNU Radio 에서 저장하는 법

  • · 흐름도 끝에 File Sink 를 달고 Type 을 complex 로 두면 complex float32 (gr_complex, 샘플당 8바이트) 파일이 돼요. 여기서 기본 형식이 이거예요.
  • · 파일에 샘플레이트가 안 적혀서 직접 넣어야 해요. 파일 이름에 2Msps·fs=2e6·433.92MHz 처럼 적어 두면 알아서 채워요.
  • · SigMF Sink (gr-sigmf) 로 저장하면 샘플레이트·중심 주파수·주석까지 읽어요. 두 파일을 같이 골라 주세요.
  • · 너무 크면 Head 블록으로 샘플 수를 정하거나, 여기서 원하는 구간만 골라 💾 이 구간 저장 으로 잘라 받을 수 있어요.
🧭 처음이라면 — 이렇게 분석해요
  1. 파일 열기 · 설정 확인 — 형식·샘플레이트·중심 주파수가 맞아야 해요. 맞으면 스펙트럼 바닥(잡음)이 대체로 평평하고, 이상하면 위에 ⚠️ 경고가 떠요. GNU Radio File Sink 의 complex 는 complex float32 예요.
  2. 신호 찾기 — 🌈 스펙트로그램은 가로가 시간, 세로가 주파수, 밝을수록 센 신호예요. 밝은 덩어리가 신호예요. 아래 🔎 신호 찾기 가 자동으로 목록을 만들어 줘요.
  3. 시간 확대 — 켜졌다 꺼지는 신호(버스트)면 목록의 [확대] 로 하나만 크게 봐요. 마우스 휠·끌기로도 돼요.
  4. 주파수 맞추기 — 녹음한 가운데(중심 주파수)에서 떨어진 신호는 [이 신호 고르기] 로 Δf(떨어진 만큼)와 대역폭을 맞춰요. 그 신호만 남기고 나머지는 걸러요.
  5. 변조 알아보기 — 아래 표처럼 모양을 보거나, 🔓 복조 에서 [복조하기] 를 누르면 자동으로 추정해요.
  6. 0·1 비트 보기 — 복조가 되면 패킷마다 비트·HEX 가 나와요. 맨 앞 1010… 은 보통 프리앰블(받는 쪽이 박자를 맞추는 머리), 그 뒤가 내용이에요. 같은 패킷이 여러 번 나오면 리모컨·센서처럼 반복 전송하는 신호예요.
  7. 막히면 ✨AI — 잰 숫자와 스펙트로그램 그림을 보고 무슨 신호 같은지, 다음에 뭘 해 보면 되는지 알려줘요 (회원).

📖 용어
  • IQ — 신호를 두 성분(I: 실수, Q: 허수)으로 담은 것. 크기와 위상을 같이 알 수 있어요.
  • 샘플레이트 — 1초에 몇 번 쟀는지. 볼 수 있는 주파수 폭과 같아요 (중심 ± 샘플레이트/2).
  • 중심 주파수 · Δf — SDR 을 맞춘 주파수가 그림의 0 Hz 예요. Δf 는 신호가 거기서 얼마나 떨어졌는지.
  • dBFS — 녹음할 수 있는 최대값을 0 으로 둔 세기. −60 은 그보다 100만 배 약함.
  • 심볼 속도 (baud) · sps — 1초에 바뀌는 기호 수, sps 는 기호 하나에 샘플이 몇 개인지 (샘플레이트 ÷ baud).
  • 맨체스터 — 비트 하나를 10·01 두 조각으로 보내는 방식. 비트가 두 배로 길게 나오면 골라 보세요.
