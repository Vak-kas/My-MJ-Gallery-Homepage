    🧾 코드

    데이터 파일과 같은 폴더에서 돌리세요. Python 은 numpy·matplotlib (+ .mat 이면 scipy, v7.3·h5 면 h5py, CSV 면 pandas), MATLAB 은 R2021a 이상.

    🧭 쓰는 법 · LaTeX 수식 쓰는 법
    1. 파일 넣기 — MATLAB 은 save('data.mat', 't', 'y'), Python 은 np.savez('data.npz', t=t, y=y) 나 scipy.io.savemat 로 저장한 걸 넣어요. 구조체(s.field)·셀(c{2})도 펼쳐 보여요.
    2. 그래프 고르기 — 변수 아래 📈 선·🌈 이미지 같은 버튼을 누르면 X 축으로 쓸 변수(t·f·snr 같은 이름)를 알아서 찾아 붙여요. 행렬이면 열마다 선, 복소수면 크기(dB)·실수·허수·성상도.
    3. 모양 다듬기 — 스타일 한 번에 고르기 에서 IEEE 1단·2단, 학위논문(LaTeX 글꼴), 발표용을 고른 뒤 필요한 것만 고쳐요. 칸 나누기(행×열)로 여러 그래프를 한 그림에.
    4. 범위 정하기 — 미리보기에서 보고 싶은 부분을 끌면 그 범위가 축 설정에 들어가요.
    5. 코드 받기 — Python·MATLAB 을 골라 복사하거나 파일로 받아 데이터 옆에서 돌리면 PDF·PNG 가 저장돼요. 모양 설정은 💾 로 저장해 다음 그림에도 같은 스타일을.

    LaTeX 수식

    • · 이름 안에서 $ … $ 사이가 수식이에요: 시간 $t$ [ms], $E_b/N_0$ [dB], $|H(e^{j\omega})|^2$, $\sigma^2 = 0.1$
    • · 아래첨자 x_1·x_{10}, 위첨자 x^2, 그리스 문자 \alpha \beta \omega \Omega, 분수 \frac{a}{b}, 글자체 \mathrm{SNR}, 단위 사이 띄어쓰기 \,
    • · $…$ 사이만 수식 (추천): 설치할 것 없이 matplotlib 이 바로 그려요. 한글도 돼요.
    • · 진짜 LaTeX: 글자 전부를 LaTeX 로 — 논문 본문과 글꼴이 완전히 같아지지만 컴퓨터에 TeX 가 깔려 있어야 하고, $ 밖의 _ % & # 앞엔 \ 를 붙여야 해요.
    • · MATLAB 은 $ 가 들어간 글자만 LaTeX 해석기로, 나머지는 고른 글꼴로 그려요 (Computer Modern 을 고르면 모두 LaTeX).

    어떤 그래프가 좋을까

    • · 시간에 따른 신호 → 선, 표본이 띄엄띄엄이면 줄기(stem), 디지털 값이면 계단
    • · BER·오차처럼 몇 자리씩 줄어드는 값 → Y 로그 눈금 + 점 모양 (흑백 인쇄면 색 순서를 흑백으로, 선 모양이 저절로 달라져요)
    • · 스펙트로그램·지도·행렬 → 이미지, 색 지도는 viridis·parula 처럼 밝기가 고르게 변하는 걸 (jet 는 없는 경계가 보여서 논문에선 피해요)
    • · 값이 어떻게 퍼져 있는지 → 히스토그램, 복소수 심볼 → 성상도 (X·Y 같은 비율)
    • · IEEE 논문 한 단 그림은 가로 3.5 in, 글자 8 pt 정도면 본문과 크기가 맞아요.
