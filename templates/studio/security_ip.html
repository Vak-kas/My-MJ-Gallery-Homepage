📮 신고하기

IP 주인이 누구인지(실제 사람)는 통신사만 알고, 수사기관이 아니면 받아낼 수 없어요. 우리가 할 수 있는 건 IP 를 관리하는 기관의 신고(abuse) 창구에 기록을 보내는 것이에요. 기관이 확인해서 그 회선·서버에 조치해요.

{% for m in ext.rdap.abuse %} ✉️ {{ m }} 에 메일 쓰기 {% endfor %} {% if ext.ipinfo.country == 'KR' or ext.rdap.country == 'KR' %} KISA 보호나라 (해킹 신고 118) ↗ 국내 IP 는 KISA 보호나라(118)로 신고하는 게 일반적이에요. 위 신고 연락처가 KRNIC(nic.or.kr)이면 주소 관리 기관이라, 통신사 담당({{ ext.rdap.contacts|join:", "|default:"관리 담당" }})에게 보내는 편이 빨라요. {% endif %} {% if ext.verdict.kind == 'scanner' %}연구용 스캐너는 신고 대신 위 연락처로 "우리 서버는 빼 달라(opt-out)"고 요청할 수 있어요.{% endif %}

⚠️ 상대 IP 로 포트 스캔·접속 시도 같은 "역추적"이나 반격은 하지 마세요. 정보통신망법 위반이 될 수 있어요. 이 화면은 이미 공개된 정보와 우리 서버 기록만 써요. 피해가 크면 경찰청 사이버수사국(ecrm.police.go.kr)에 신고하세요.
